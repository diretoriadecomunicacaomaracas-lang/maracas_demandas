# FONTES

A interface usa **Inter**. Para não depender de CDN (adendo item 9), coloque o arquivo variável em `public/fonts/Inter-Variable.woff2` (licença SIL Open Font License). O `globals.css` já referencia `/fonts/Inter-Variable.woff2` via `@font-face`. As fontes da marca (Gotham Ultra, Neulis Cursive Light) pertencem à identidade e **não** são usadas na UI — apenas no arquivo oficial da logomarca.
